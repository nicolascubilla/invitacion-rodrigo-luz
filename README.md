# Invitación Rodrigo & Luz

Invitación digital estática para Francisco Rodrigo Aquino y Luz Mabel Cubilla. No requiere backend ni dependencias locales.

## Vista local

Con Apache activo en XAMPP, abrir:

`http://localhost/invitacion-rodrigo-luz/`

También puede abrirse `index.html` directamente para una revisión visual, aunque Apache es la prueba recomendada.

## Configuración

Todos los datos editables están en `js/config.js`. Las URLs de ceremonia y recepción están vacías intencionalmente hasta recibir las direcciones oficiales. La galería usa copias locales optimizadas en `assets/images/` y la música integrada en `assets/audio/` se activa desde la pantalla de apertura, después de una interacción del visitante.

## Publicación

El proyecto usa rutas relativas y puede publicarse en GitHub Pages cuando sea aprobado. No incluye comandos ni automatización de publicación.
